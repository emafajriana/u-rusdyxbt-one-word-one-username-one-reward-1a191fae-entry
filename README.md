Entry for the make.fun bounty [One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

The program (`main.py`, Python standard library only) writes the entrant's own
make.fun username — one word and nothing else — to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that environment variable is set),
then reads it back and verifies it against the competition gate: UTF-8 text of
1 to 30 characters, not only white space.

## Run

```sh
python3 main.py
```
